FLUJO DE USO TÍPICO (PARA EXAMEN)
================================================================================

ESCENARIO: Inciso e pide calcular dT/dt|_t=15 con h=0.01 usando RK4

PASO 1: COMPILAR (una sola vez)
  $ bash compilar.sh

PASO 2: EJECUTAR RK4 CON h=0.01
  $ cd "Diferenciacion Numerica/Ecuaciones Diferenciales"
  $ ./rk4
  > 10 20          # intervalo [a,b]
  > 60 0           # condiciones iniciales y1(a), y2(a)
  > h              # ingresar h
  > 0.01           # valor de h

  → Genera: rk4_0.01.txt

PASO 3: GRAFICAR Y ANALIZAR
  $ cd ../..
  $ ./Graficador
  > 1              # Opción: graficar TODOS
  
  O por línea de comandos:
  $ ./Graficador 0.01

  → Genera: comparacion.png

PASO 4: ANÁLISIS MANUAL (INCISO e)
  • Abre rk4_0.01.txt en editor de texto
  • Busca T(15.00), T(14.99), T(15.01)
  • Calcula dT/dt centrado: (T[15.01] - T[14.99]) / (2*0.01)
  • Compara con exacto: 0.11236

RESULTADO FINAL: PNG con gráfica comparativa + análisis numérico

EDITAR FUNCIONES (PARA DIFERENTES PROBLEMAS)
================================================================================

EJEMPLO 1: Cambiar f(x,y) en Euler.cpp

Antes:
  double f(double x, double y) {
      return -2.0 * x * y;
  }

Después (para dy/dx = sin(x) - y):
  double f(double x, double y) {
      return sin(x) - y;
  }

Luego recompila: g++ -g -o euler Euler.cpp -lm

---

EJEMPLO 2: Cambiar funciones en Rk4.cpp (sistema 2×2)

Antes (Newton's cooling):
  double f1(double x, double y1, double y2) {
      return (L * L / (D * M_PI * M_PI)) * log((T0 - T1) / (y1 - T1)) - x;
  }

Después (ejemplo Lotka-Volterra: dP/dt = aP - bPQ, dQ/dt = cPQ - dQ):
  double f1(double x, double y1, double y2) {
      return 1.5*y1 - 0.1*y1*y2;  // P: presa
  }
  double f2(double x, double y1, double y2) {
      return 0.08*y1*y2 - 0.9*y2;  // Q: depredador
  }

Métodos implementados:
  • Euler (Forward): dy/dx ≈ [y(x+h) - y(x)] / h, Orden O(h)
  • Heun (RK2): Predictor-Corrector, Orden O(h²)
  • RK4: 4 pendientes, Orden O(h⁴)

Fórmulas numéricas usadas:
  • Diferencia centrada: f'(x) ≈ [f(x+h) - f(x-h)] / (2h), Orden O(h²)
  • Newton's cooling: dT/dt = (L²/Dπ²)·ln((T₀-T₁)/(T-T₁)) - t
